# AI VivaEdge 🚀

AI VivaEdge is an online, adaptive oral examination (viva) platform designed to automate and streamline the assessment process for students at any educational level—from primary school to university undergraduates. By leveraging artificial intelligence, the platform conducts structured oral interviews, asks intelligent follow-up questions based on student input, and provides instant, detailed grading analytics for educators.

## ✨ Features

- **Dual-Persona Dashboard:** Separate, tailored workflows for Teachers/Examiners and Students.
- **Dynamic Viva Configuration:** Teachers can customize the academic level (Primary to University), specify the subject topic, and provide custom syllabus text or reference material for the AI to base its questions on.
- **Adaptive AI Interviewing:** A clean student interface featuring a live question panel, responsive input capturing, and simulated speech-to-text functionality.
- **Granular Analytics & Performance Reports:** Generates an immediate scorecard upon submission, detailing overall percentage scores, conceptual clarity ratings, and an interactive question-by-question transcript highlighting strengths and critical gaps.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Routing & State:** Modern SPA routing and state architecture
- **Development Tooling:** Built and prototyped via Loveable.dev
